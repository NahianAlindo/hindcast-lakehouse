# sonic-lakehouse

A production-patterned data platform for my personal Spotify listening history —
Airflow, Spark, dbt, Snowflake, Power BI, provisioned end-to-end with Terraform.

**Status:** scaffolding / Phase 0 (accounts + local environment). No pipeline code yet.
